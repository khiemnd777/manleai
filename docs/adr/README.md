# Architecture Decision Records

Use ADRs when a decision should prevent future agents from re-litigating the same architecture question.

Recommended filename:

```txt
docs/adr/0001-short-title.md
```

Template:

```md
# ADR 0001: Title

## Status

Accepted

## Context

What problem or constraint forced this decision?

## Decision

What are we choosing?

## Consequences

What gets easier, what gets harder, and what must future agents preserve?
```
