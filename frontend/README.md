# Frontend

Next.js admin frontend for the AI Receptionist pilot foundation.

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## Environment

```bash
NEXT_PUBLIC_API_BASE_URL=http://localhost:18089
```

## Implemented Screens

- `/login`
- `/onboarding`
- `/dashboard`
- `/dashboard/integrations`

The sidebar includes future product areas with explicit milestone boundaries. Those pages do not fake data or production behavior.
